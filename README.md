# JSlink

개인 PC와 LDPlayer에 접속하는 Android 원격 제어 앱입니다.

[최신 APK 다운로드](https://github.com/TovLab/JSlink/releases/latest/download/JSlink.apk)

설치 후 기존 JSlink 계정으로 로그인하고, PC 관리 프로그램에서 새 기기를 승인합니다. 기존 앱 위에 업데이트 설치하면 로그인 상태와 기기 승인을 유지합니다.

로그인 후 켜진 PC로 자동 접속하며 마지막 접속 방식을 기억합니다. 미리보기의 **마이**에서 접속 방식을 바꾸거나 다른 PC를 선택할 수 있습니다. 다른 앱에서 돌아오면 살아 있는 연결을 재사용하거나 이전 화면으로 다시 연결합니다.

0.3.2부터 한 번 접속한 승인 기기는 다음 실행에서 마지막 PC의 연결 준비로 바로 들어갑니다. 마지막 PC가 꺼져 있으면 다른 온라인 PC를 찾습니다. 앱에 저장하는 주소에는 PC 식별자와 접속 방식만 들어가며, 실제 접속 권한은 서버에서 계속 확인합니다.

보이는 화면 최대 4개의 미리보기를 초당 약 4장씩 갱신합니다. 백그라운드에서는 영상 전송을 멈추며, 실제 연결은 최대 60초 유지하고 그 이후에는 복귀할 때 재연결합니다.

가로 전체화면의 왼쪽 검은 여백 전체에서 위아래로 밀어 화면을 전환합니다. 영상 내부의 터치는 그대로 원격 PC·LDPlayer에 전달합니다.

앱의 로그인 화면에서 **업데이트 확인**, 또는 미리보기의 **마이 → 업데이트 확인**을 누르면 새 버전을 확인할 수 있습니다. 새 버전의 APK를 내려받은 뒤 Android 설치 화면에서 업데이트를 진행합니다.

이 저장소는 Android 설치 파일과 업데이트 정보를 배포합니다. PC 원격 연결 프로그램은 별도로 실행해야 합니다.
